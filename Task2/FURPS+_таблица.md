# FURPS+ таблица 

FURPS+ таблица показывает модель описания функциональных и нефункциональных требований, которые согласовываются с заказчиком и 
включаются в план реализации проекта.
Функциональные требования описывают то, что система должна делать, т.е. конкретные функции.     
Нефункциональные требования описывают то, как система будет реализовывать функции при работе.   

| Код    | Требования                                                                                                                                                                               | Комментарий                   |
|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                                                                                                       |                               |
| F1     | На сайте клиенты видят список доступных депозитов с актуальными ставками                                                                                                                 |                               |
| F2     | Клиент может подать заявку на депозит, оставив свой номер телефона и ФИО                                                                                                                 |                               |
| F3     | Менеджеры кол-центра обрабатывают заявку клиента                                                                                                                                         |                               |
| F4     | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированными ставками                                                                          |                               |
| F5     | Клиент может подать заявку на открытие депозита                                                                                                                                          |                               |
| F6     | Подтверждение заявки на открытие депозита осуществляется по смс                                                                                                                          |                               |
| **U**  | **Удобство использования (Usability)**                                                                                                                                                   |                               |
| U1     | Интерфейс должен соответствовать принятым в компании цветам и брендированным элемантам                                                                                                   |                               |
| **R**  | **Надёжность (Reliability)**                                                                                                                                                             |                               |
| R1     | Данные должны передаваться по защищенному протоколу - TLS 1.2+                                                                                                                           |                               |
| R2     | Все сервисы должны работать 24/7 и быть доступны в 99,9%                                                                                                                                 |                               |
| **P**  | **Производительность (Performance)**                                                                                                                                                     |                               |
| P1     | Предусмотреть возможность горизонтального и вертикального масштабирования всех компонентов                                                                                               |                               |
| P2     | Для АБС предусмотреть возможность только вертикального масштабирования                                                                                                                   | Из-за ограничения базы данных |
| P3     | Отклик по всем операциям должен быть максимально быстрым и занимать не более 100мс                                                                                                       |                               |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                                                                    |                               |
| S1     | Должна быть поддержка интеграционного тестирования                                                                                                                                       |                               |
| **+R** | **+ Ограничения (Restricitions)**                                                                                                                                                        |                               |
| +R1    | При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке. Новые технологии должны быть совместимы с существующими платформами разработки |                               |
| +R2    | Для очередей сообщений использовать Kafka                                                                                                                                                |                               |
